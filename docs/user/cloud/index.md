云联想缺省关闭。打开后，输入拼音时会将当前拼音与光标附近的文字发送给**用户选择或自行填写的** AI 服务商，换回候选词与整句补全。
数据直接从本机发送到服务商，不经过青简；密码框与应用声明为私密的输入框中不发送。

## 开启

「偏好设置 → 云服务」：选择服务商、填写 API 密钥，再打开开关。macOS 内置 DeepSeek、MiniMax、OpenAI、智谱 GLM、Kimi、通义千问的地址与默认模型；选择后仍可手动修改模型。选「自定义」可填写其他 OpenAI 兼容的服务。
文本框按回车或离开时保存。每个服务商单独保存密钥，自定义服务按接口地址区分；切换服务不会把上一家的密钥发送给下一家，未设置密钥时请先填写。已保存的密钥只保存在本机，不随配置文件导出，也不回显。菜单栏「中 / 英」之后带 ☁︎ 表示联想已开启。
MiniMax 的接口地址是 `https://api.minimaxi.com/v1`，预设使用 `MiniMax-M3` 并关闭思考，直接返回联想。已有模型配置保留；如果还在使用 `MiniMax-M2.7-highspeed`，请把「模型」改成 `MiniMax-M3`。
M2.x 模型无法关闭思考，通常比直接回答的模型慢；若继续输入，过期结果不会插入当前候选。`MiniMax-M3.1-Flash-Preview` 同样不能关闭思考。
继续打字时，只保留最新输入的云联想，取消旧请求的等待；清空拼音或切换窗口也会取消。接口本身仍可能较慢，M3 关闭思考后按你设置的超时时间等待，不再强制等 15 秒。

同一接口与密钥的云查询一次只发送一个，内容完全相同的在途查询共用一次请求。继续输入后，尚未发送的过期查询会跳过；已经发送的查询会等到完成或超时，过期结果不会显示。后续云查询可能需要等待，但本地候选可照常选择。猜词仍在停键 300 毫秒后触发，候选翻译仍在高亮稳定 500 毫秒后触发；等待也计入原有请求超时。

填写完成后点「测试连接」，将以当前地址、模型、密钥发送一条最小请求，结果显示在窗口底部：成功时显示模型名与耗时，失败时显示原因。
输入法由系统启动，不读取终端中设置的代理；若需通过代理访问服务商，请在系统设置中设置系统代理，或使用 TUN 模式的代理工具。

发送的内容：所敲字母、本机的切分、光标前后各几十个字的上下文、本机给出的候选。详见 [数据与日志](../help/data-and-logs.md#云联想发什么)。

## 云端候选词

输入拼音时停顿 300 毫秒后，云猜词返回时从候选第一页**第二位**开始显示，缺省最多两项（「云服务」页可调为 0 至 4）。按 `2` 选择第一项云猜词；第二项通常是 `3`，上屏消耗整段拼音。

- 本地首选保留在第一位，`Space` 仍上屏本地首选，其余本地候选顺延。自定义短语有固定位置时，云猜词排在最后一个固定位置之后。
- 已用方向键选中会被移动的候选，或已经翻页时，不插入晚到的云猜词，避免改变正在选择的词。
- 未返回、无结果、超时均不改变显示，不预留、不画占位。
- 选中词库中没有的云端词会记为用户词（按所敲的读音记录，不按云端给出的读音），下次本地直接给出。
- 云端可纠错：`zhgdoima` 同样可得到「这个东西吗」。
- 支持简拼和全拼混用：例如 `oxlx`、`ouxlx` 可猜「呕心沥血」，`wxcd` 可猜「卧薪尝胆」。没有明确上下文时优先考虑常用词、固定短语和成语；同一简拼可能对应多个词，云端不保证每次都命中。
- 少量拼音打错也会尝试纠正，例如 `ouximlixue` 可猜「呕心沥血」；结果仍需通过拼音及已知汉字读音的核对。云端响应前可照常选择本地候选，返回后云猜词从第二位开始显示，按对应数字键选择。

## 整句补全

同一次请求还返回一条整句：以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵显示在拼音右侧。
`Tab` 接受，继续输入则替换。有应用上下文时接着上下文续写。

## 译词自动补充

随包释义表中没有译词的词，在输出后会单独向云端询问一次（只发送该词），返回的译词存入本机的个人释义表，下次候选旁即有显示。
关闭云服务后不再发送任何请求。

## 不联想的情况

上屏之后不联想；英文模式、以 `v` 开头的算式不联想；密码框中不联想。
